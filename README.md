# Avaliação de Desempenho — API

API REST para gerenciamento de avaliações de desempenho de colaboradores.

## Tecnologias

- Python 3.12
- Django 5.1
- Django REST Framework
- PostgreSQL
- Docker

## Como executar

### Com Docker

```bash
docker-compose up --build
```
